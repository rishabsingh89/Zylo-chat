# Zylo Chat

Zylo Chat is a real-time full-stack chat application built with FastAPI backend and React (Vite) frontend.

## Features
- Real-time Messaging (WebSockets)
- User Authentication (JWT)
- Direct & Group Chats
- Friend Request & Management System
- File / Attachment Uploads
- Sleek & Modern Responsive UI

## Project Structure
- `backend/`: FastAPI application with SQLite / SQLAlchemy database.
- `frontend/`: React + Vite single page application.

## Getting Started

### Prerequisites
- Node.js (v18+)
- Python (v3.10+)

### Running the Application
From the root directory, run:
```bash
npm run dev
```
Or execute `start_all.bat` on Windows.
